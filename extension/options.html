말풍선 렌즈

만화 속 대사를 번역해서 원래 말풍선 자리에 보여줘요. 이미지는 이 PC를 떠나지 않아요.

화면 언어

다른 언어는 이름이나 코드를 입력하세요. 처음 선택하면 Claude로 화면 문구를 번역해 저장해요.

시작하기

확인 중
  1. 1

    로컬 도우미 설치

    번역은 이 PC의 도우미 프로그램이 해요. 한 번만 설치하면 크롬에서 알아서 켜요.

    BalloonLens 폴더의 tools\install_windows.cmd를 더블클릭하세요. 설치가 끝나면 이 페이지로 돌아오면 돼요.

  2. 2

    도우미 실행

    번역을 켜면 자동으로 켜져요.

  3. 3

    번역 방식

    Claude 구독에 로그인해서 쓰거나(권장), 이 PC의 로컬 모델을 Ollama에서 받아 쓸 수 있어요.

    앱의 번역 횟수 제한은 없어요. 남은 사용량은 번역에 로그인한 Claude 계정의 5시간·7일 기준이며, 최대 5분 간격으로 갱신해요. 같은 계정의 Claude Code·Claude 앱과 사용량을 공유해요.

  4. 4

    사이트 이미지 읽기 허용

    만화 이미지를 읽으려면 필요해요. 이미지는 이 PC 밖으로 나가지 않아요.

  5. 5

    샘플로 확인

    예제 만화 한 장을 실제로 번역해 봐요.

작품별 말투·용어·기억

문맥 모드(Qwen)에서 적용돼요. 작품 주소 아래의 페이지들에 같은 규칙을 사용합니다.

작품 기억

등록한 작품 주소 아래 페이지를 번역하면, 원문과 번역(직접 고친 표현 포함)을 이 PC에 기억해서 다음 페이지 번역에 참고해요. 사이트가 페이지에 번호를 붙이면 뒤 페이지 내용은 앞 페이지에 쓰지 않아요. 아래 칸에는 직접 확인한 내용만 적어 주세요.

번역문 모양

자동으로 켜는 사이트

    팝업에서 “이 사이트에서 자동으로 켜기”를 켜면 여기에 추가돼요.

    단축키

      설정 백업

      번역 설정, 자동 사이트, 작품별 말투·용어와 작품 정보(제목·줄거리·인물)를 파일로 저장하거나 불러와요. 기억한 페이지, 번역 캐시, 연결 토큰은 넣지 않아요.

      문제 해결

      도우미 기록: %LOCALAPPDATA%\BalloonLens\helper.log

      로컬 번역은 이 PC의 도우미와 Ollama에서만 실행돼요. 구독 번역은 대사 글자만 Claude 서버로 보내고, 이미지는 보내지 않아요.

      구독 로그인은 개인 PC에서만 쓰세요. 이 확장을 다른 사람에게 나누거나 배포하면 안 돼요.
