# 구독 CLI 번역 엔진 구현 기록 (v0.5.0)

시작: 2026-10-10. 기준 설계: [2026-10-09-subscription-engine-v2.md](2026-10-09-subscription-engine-v2.md).
사용자 지시: 전부 개발될 때까지 계속 진행. 추가 기능과 개선은 직접 판단해서 함께 진행. 판단이 필요한 일은 직접 결정하고 여기에 기록.

## 2. 추가로 넣기로 한 기능과 개선 (판단)

- 한도 자동 보호: 5시간·7일 호출 상한, 소진 시 큐 정지, 재개 시각 표시. 호출 직전마다 확인 (D20)
- 한도 소진 대응: "로컬로 계속" 한 번 누르기
- 사용량 원장: 대사 텍스트 없이 호출 수와 토큰 수만 저장. 막힌 호출은 기록하지 않음
- 사용량 보정: 공식 화면 퍼센트를 직접 입력해서 호출당 소모율 추정
- 결과 검사 강화: 메타 발화, 비밀 패턴(키·인증 파일 경로), 대사에 없던 URL·경로·명령 탐지
- 긴 페이지 분할: 24줄 단위 호출. 한 번에 한 호출(`CLI_PARALLEL=1`)일 때만 앞 청크 마지막 2줄을 문맥으로 이어 줌. 병렬일 때는 D53
- 백엔드별 직렬화: 페이지 작업과 한 줄 수정이 같은 상한을 함께 통과하지 못하게 함
- 상태 점검 캐시: 120초 동안 CLI 기동을 줄임. 헬퍼 시작 때 한 번 미리 확인
- 설정 마이그레이션: 기존 `model` 값을 그대로 보존하고 업그레이드 때 자동 전환하지 않음
- 블라인드 평가 도구: 백엔드 이름을 숨긴 A/B 쌍을 만들고 사람 판정을 집계 (LLM 자체 평가 없음)
- 설치 스크립트: Ollama는 선택 설치, Claude Code 버전·로그인 상태 확인, 로그인 명령 출력 정리
