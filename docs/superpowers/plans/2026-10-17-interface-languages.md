# 화면 언어 선택

사용자 범위: 만화 번역 언어가 아니라 데스크톱 프로그램·확장의 버튼과 안내문 언어를 선택한다. 언어 선택을 영어·한국어·일본어에 한정하지 않는다. 기존 작업 커밋·푸시 후 별도 변경으로 저장한다. 테스트는 요청하지 않았으므로 작성·수정·실행하지 않는다.

구현:

- `extension/ui_catalog.json`: 한국어 원문 기준 영어·일본어 기본 화면 문구. 데스크톱과 확장이 공유한다.
- `helper/balloonlens/ui_locale.py`: 화면 문자열 치환, 입력 가능한 언어 이름/코드, 추가 언어 생성·저장. 숫자·오류·시간 등의 자리표시자는 유지한다.
- `GET /v1/ui-locale`: 기본 제공 또는 저장된 화면 문구 조회. `POST /v1/ui-locale`: 사용자가 추가 언어를 명시적으로 선택했을 때만 Claude로 준비한다. 화면 언어 준비도 기존 로그인·구독 제한 응답·호출 간격을 따른다.
- 데스크톱은 편집 가능한 언어 선택란, 확장은 브라우저가 제공하는 언어 목록과 직접 입력란을 사용한다. 고정 언어 목록으로 요청을 제한하지 않는다.
- 추가 언어는 50개 문구 단위로 기존 Claude 경로를 호출한다. 언어당 첫 준비는 여러 호출을 소비한다. 문구 전체와 자리표시자가 완성된 경우에만 저장한다. 실패 시 기존 언어를 유지하고 안내한다.
- 캐시는 사용자 데이터 폴더의 `ui-locales`이며 카탈로그 버전을 키에 포함한다. 소스/배포물에 로그인이나 생성된 사용자 캐시는 포함하지 않는다.
- 데스크톱의 원문·번역 선택 값은 기존 한국어 키로 저장한다. 표시 이름만 번역해 화면 언어를 바꿔도 번역 요청의 언어 코드가 유지된다.
- 확장은 자신의 문서와 닫힌 shadow root만 갱신한다. 만화 대사, 원문·번역 입력란, 작품 지침, 미리보기 대사에는 화면 언어를 적용하지 않는다.

상태: 소스 구현. 테스트·브라우저 실행·추가 언어 실제 모델 호출은 하지 않았다. 최신 도우미 재시작과 확장 새로고침이 필요하다. EXE는 소스 실행 런처이므로 이 변경만으로 다시 빌드할 필요는 없다.
