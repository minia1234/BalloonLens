# 동봉된 화면 언어

사용자 범위: 데스크톱 프로그램·확장의 버튼과 안내문 언어를 선택한다. 화면 문구는 직접 작성해 포함하며 Claude는 콘텐츠 번역에만 사용한다. 이전 구현의 실행 중 화면 문구 생성 방식은 제거했다.

## 구현

- `extension/ui_catalog.json`: 한국어 원문 기준 영어·일본어 화면 문구.
- `extension/ui_languages.json`: 추가 17개 언어의 버튼·메뉴·주요 상태 문구와 선택 목록. 일부 상세 도움말은 영어 기본 문구를 사용한다. 전체 언어의 완역을 의미하지 않는다.
- `helper/balloonlens/ui_locale.py`: 로컬 JSON을 읽어 문구를 선택·치환한다. 모델·인증·HTTP·스레드 풀·생성 캐시 의존성이 없다.
- 확장은 서비스 워커에서 동봉 JSON만 읽는다. 언어 선택 시 도우미를 켜거나 원격 서비스를 부르지 않는다.
- 데스크톱도 같은 동봉 파일을 즉시 적용한다. 저장된 원문·목표 언어 코드는 표시 언어와 별개로 유지한다.
- `/v1/ui-locale` GET/POST와 Claude 화면 문구 생성, 생성 대기, 자동 생성 안내를 제거했다. 기존 사용자 데이터 폴더의 생성 캐시 파일은 삭제하지 않는다.
- 목록 밖의 언어를 입력하면 파일이 없다고 알리고 기존 언어를 유지한다. 새 언어는 파일에 직접 추가한다.
- 언어 전환은 인터넷·로그인·구독 사용량을 요구하지 않는다. 만화 번역과 Claude 계정 사용량 조회는 기존 경로를 사용한다.

상태: 소스 구현. 사용자 규칙에 따라 테스트·실행 확인은 하지 않았다. 프로그램과 확장을 다시 열면 적용되며, 이전 도우미의 생성 API도 제거하려면 도우미를 재시작한다. EXE는 소스 실행 런처이므로 다시 빌드할 필요가 없다.
