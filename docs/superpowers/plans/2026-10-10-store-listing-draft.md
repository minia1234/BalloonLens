# 크롬 웹 스토어 비공개 게시 초안 (2026-10-10, 사용자 결정 전)

이 문서는 게시 결정이 나면 바로 쓸 수 있게 준비한 초안이다. 아직 아무것도 올리지 않았다. 확장 ID는 게시 후 새로 생기므로, 게시 뒤 헬퍼 허용 목록과 설치 스크립트를 함께 고쳐야 한다 (사용자 편의성 검토 2번 항목).

## 1. 기본 정보

- 이름: 말풍선 렌즈 · BalloonLens
- 공개 방식: 비공개(unlisted) 권장. 링크를 가진 사람만 설치한다. 검색에는 나오지 않는다. 공개(public)는 사용자가 따로 결정한다.
- 카테고리: 생산성 또는 도구 (스토어 메뉴에서 확인)
- 언어: 한국어 (기본), 영어는 나중에

## 2. 짧은 설명 (약 132자 안팎, 게시 화면에서 글자 수 확인)

> 만화 이미지 속 대사를 읽어 번역하고 원래 말풍선 자리에 보여줘요. 이미지는 이 PC를 떠나지 않아요.

## 3. 자세한 설명 (초안)

말풍선 렌즈는 웹툰과 만화 페이지의 대사를 읽어 한국어로 바꾸고, 원래 말풍선 자리에 다시 보여 줍니다.

- 이미지는 이 PC에서만 처리합니다. 문자 인식(OCR)과 글자 지우기는 사용자의 PC에서 돌아갑니다.
- 번역은 두 가지 중 하나를 고릅니다. 이 PC의 로컬 모델(Ollama), 또는 사용자가 이미 가진 Claude 또는 Codex 구독입니다. 구독을 고르면 대사 글자만 해당 서비스로 보내며, 처음 쓰기 전에 동의를 받습니다.
- 번역문을 직접 고칠 수 있고, 고친 내용은 같은 페이지에 다시 나타납니다.

이 확장은 이 PC에 함께 설치하는 로컬 도우미(BalloonLens 설치 창으로 설치)와 함께 동작합니다. 도우미 없이는 번역하지 않습니다.

## 4. 권한 설명 (스토어 심사에 그대로 씁니다)

| 권한 | 왜 필요한가 |
|---|---|
| storage | 설정, 작품별 용어, 구독 동의 상태를 사용자 PC에 저장 |
| activeTab | 사용자가 누른 탭에서만 번역을 시작 |
| scripting | 번역 결과를 페이지 위에 그리기 위해 페이지에 코드를 넣음 |
| nativeMessaging | 이 PC의 로컬 도우미를 켜고 연결 (설치 창이 등록한 호스트만 사용) |
| 호스트 `http://127.0.0.1:8787/*` | 이 PC의 로컬 도우미와만 통신 |
| 선택 호스트 `<all_urls>` | 사용자가 자동 실행을 켠 사이트에서만 페이지 이미지를 읽기 위해 요청 |

## 5. 개인정보 처리 (스토어 "데이터 사용" 항목 초안)

- 수집하는 것: 없음. 확장 개발자가 받는 데이터는 없다. 분석이나 원격 추적 도구를 쓰지 않는다.
- 사용자 PC에서만 처리하는 것: 페이지 이미지, 대사 인식 결과, 번역 캐시, 작품 설정, 사용량 기록(호출 수와 토큰 수, 대사 글자는 기록하지 않음).
- 외부로 나가는 것:
  - 페이지 이미지를 가져올 때는 그 사이트에 요청한다. 사용자가 보고 있는 페이지와 같은 방식이다.
  - 구독 번역을 고른 경우, 대사 글자만 사용자의 Claude 또는 Codex 계정을 통해 해당 서비스로 간다. 이미지는 보내지 않는다.
  - 사용자가 누른 Ollama 다운로드 링크는 브라우저로 열린다.
- 사용자 데이터를 판매하거나 광고에 쓰지 않는다.

## 6. 게시 전에 확인할 것

- 개발자 등록비: 현재 가격을 대시보드에서 확인한다 (보도된 금액은 2020년 기준이다).
- manifest의 `key` 필드: 스토어 업로드에 필요한지, 제거해야 하는지 공식 문서로 확인한다. 확장 ID가 바뀐다는 점은 확실하다.
- 구독 CLI 자동화의 약관 검토 (계획서 M0 #9). 스토어 심사에서 이 기능을 어떻게 설명할지 결정해야 한다.
- 개인정보처리방침 페이지: 위 5번 내용을 공개 주소에 올려야 한다. 주소는 사용자가 정한다.
- 스크린샷 3장 이상: 설치 창, 번역 전후 화면, 설정 화면.
- 게시 후 할 일: 헬퍼 허용 목록(`BALLOONLENS_EXTENSION_IDS`)에 새 ID 추가, 설치 스크립트의 네이티브 호스트 `allowed_origins`에 새 ID 추가, 전환 기간 동안 두 ID 모두 허용.

## 7. 사용자가 정할 것

1. 게시할지 (추천: 비공개로 게시)
2. 등록비와 계정 (사용자 본인 계정으로 해야 한다)
3. 개인정보처리방침을 둘 주소
4. 구독 CLI 기능을 스토어 설명에 어떻게 적을지
