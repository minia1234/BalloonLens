# 번역 횟수 제한 제거와 Claude 잔여 사용량 표시

요청: 앱 자체 번역은 무제한으로 하고 현재 Claude 남은 사용량만 표시한다.

1. 앱의 횟수 상한 검사, 설정 입력, 수동 퍼센트 보정을 제거한다. 예전에 DB에 저장된 상한도 적용하지 않는다. 기존 기록·캐시·로그인 파일은 보존한다.
2. 번역 전용 Claude 로그인 폴더의 계정으로 사용량 메타데이터를 조회한다. `https://api.anthropic.com/api/oauth/usage`가 실제 계정에서 5시간·7일 사용률과 초기화 시각을 반환함을 확인했다. 모델 호출은 하지 않았다. 이 경로는 Claude의 내부 사용량 인터페이스로, 실패 시 확인 불가 또는 명시된 마지막 확인값을 표시한다.
3. 조회는 백그라운드에서 수행하고 성공 결과를 5분 공유한다. 중복 요청과 429 오류 시 반복 조회를 막고, 인증 정보나 원문을 확장에 전달하지 않는다.
4. 팝업과 설정 카드에는 남은 비율, 초기화 시각, 확인 시각만 표시한다. 실제 Claude 한도 응답의 일시 대기·로컬 전환은 유지한다.

구현 상태: 앱 횟수 제한과 수동 보정 API·화면을 제거하고 Claude 잔여 사용량 조회를 연결했다. 실행 중인 이전 도우미에도 기존 설정 경로로 상한을 0/0으로 저장해 횟수 제한을 해제했다. 새 사용량 표시를 실행에 반영하려면 도우미 재시작과 크롬 확장 새로고침이 필요하다.

사용자 지시(2026-10-16): 명시적으로 요청하지 않으면 구현만 진행하고 테스트는 작성·수정·실행하지 않는다. 진행 중이던 테스트는 중단했으며 프로젝트 `AGENTS.md`에 규칙을 저장했다. 기존 미커밋 성능 변경은 보존한다.
