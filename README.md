# 말풍선 렌즈 · BalloonLens

만화 이미지 속 대사를 읽어 번역하고, 원래 말풍선 자리에 한국어로 보여주는 프로그램입니다. Windows 화면 범위 번역과 크롬 확장 중에서 골라 쓸 수 있습니다.

- **상태:** 0.5.0 베타. 개인 PC에서 본인이 쓰는 것을 전제로 합니다.
- **구성:** Windows 프로그램 또는 크롬 확장(화면 표시) + 로컬 도우미(글자 인식, 번역, 저장). 글자 인식과 화면 표시는 이 PC에서 돌아갑니다.
- **기획서:** [BalloonLens_Product_Plan_v1.0.md](BalloonLens_Product_Plan_v1.0.md)

## 빠른 시작 (Windows)

### 크롬 없이 화면 범위 번역

1. `Setup.cmd`로 번역 환경을 준비합니다. 크롬 확장은 설치하지 않아도 됩니다.
2. 프로젝트 폴더의 `BalloonLens.exe` 또는 `BalloonLens.cmd`를 더블클릭합니다.
3. 처음이면 **Claude 구독 로그인**으로 로그인한 뒤, **범위 선택**을 누르고 브라우저나 이미지 뷰어의 번역할 부분을 드래그합니다.
4. 선택한 범위만 자동 번역합니다. 스크롤이나 페이지 넘김으로 화면이 바뀌고 잠시 멈추면 다시 번역하며, 결과를 원문 위에 표시합니다.

- 번역 표시 아래의 원래 프로그램을 그대로 클릭하고 스크롤할 수 있습니다.
- `Ctrl+Alt+R`: 범위 다시 선택. `Ctrl+Alt+T`: 이번 화면 번역. `Ctrl+Alt+O`: 원문/번역 표시. `Ctrl+Alt+S`: 자동 번역 시작/중지.
- 화면이 바뀌면 이전 번역 작업을 취소하고, 이전 화면의 응답을 새 화면에 표시하지 않습니다.
- 같은 화면을 반복 번역하지 않으며, 재실행 시 범위를 불러오고 **자동 번역 시작**을 누르면 이어갑니다.
- 작은 말풍선에서 잘린 번역은 프로그램 창의 **대사 목록**에서 읽을 수 있습니다.
- 여러 모니터에서도 범위를 고를 수 있습니다. 범위는 화면 좌표에 고정되므로 창을 옮기면 범위를 다시 지정하세요.
- 기존 도우미·Claude 로그인·번역 캐시를 함께 사용합니다. 이미지는 Claude에 보내지 않습니다.
- 화면 번역은 Windows용이며, 화면 캡처가 차단된 앱이나 보호된 영상은 번역할 수 없습니다.

### 배포 ZIP으로 설치

1. ZIP을 풀고 `BalloonLens-Setup.exe`를 실행합니다.
2. **전부 자동으로 준비**를 누릅니다. 처음에는 수 GB를 받아서 시간이 걸립니다.
3. **크롬 확장 설치 안내**의 3단계를 따릅니다. 크롬은 확장을 조용히 설치하지 못하게 막고 있어서, `압축해제된 확장 프로그램 로드`는 사람이 한 번 눌러야 합니다.
4. **Claude 로그인 창 열기**로 열린 창에서 직접 로그인합니다. 설치 창에서 **상태 다시 확인**을 누릅니다.

설치 프로그램은 로그인 정보를 다루지 않습니다. 확장은 프로필마다 따로 설치되므로 평소 쓰는 프로필을 고릅니다.

### 저장소에서 설치

`Setup.cmd`를 한 번 실행합니다. Python 환경, 번역 패키지, 도우미 자동 실행 등록, Claude Code 설치 확인을 순서대로 준비합니다.

- Ollama와 로컬 모델은 선택 사항입니다. 함께 설치하려면 `Setup.cmd -WithLocal`을 씁니다.
- 크롬에서 `chrome://extensions` → 개발자 모드 → **압축해제된 확장 프로그램 로드** → `extension` 폴더를 고릅니다.

### 번역 켜기

1. 팝업에서 번역 방식을 고릅니다.
2. **번역 켜기**를 누르거나 `Alt+Shift+T`를 누릅니다.

## 번역 방식

| 방식 | 모델 | 밖으로 나가는 것 | 번역 횟수 |
|---|---|---|---|
| Claude 구독 | `claude-haiku-5-5` (Claude Code `claude -p`) | 대사 글자, 작품 지침·용어집, 작품 기억의 앞 페이지 대사 | 앱 제한 없음 · Claude 구독 한도 적용 |
| 로컬 Ollama | `qwen3.5:9b`(기본), `qwen3:8b`, `translategemma:4b` | 없음 | 없음 |

- **이미지는 어떤 번역 방식에도 보내지 않습니다.** 글자 인식은 이 PC에서 합니다.
- 앱 자체의 번역 횟수 제한은 없습니다. 팝업과 설정에는 번역 계정의 실제 5시간·7일 남은 사용량과 초기화 시각만 표시합니다. 사용량 조회는 최대 5분 간격이며, 조회 실패 시 확인 불가 또는 마지막 확인값을 표시합니다.
- Claude 번역은 전용 로그인 폴더를 씁니다. 개인 `CLAUDE.md`는 번역 호출에 들어가지 않습니다.

## 쓰는 법

### 화면 언어

Windows 프로그램과 확장의 팝업·설정에서 **화면 언어**를 선택하고 **적용**을 누릅니다. 화면 언어는 만화 원문·번역 대상 언어와 별개입니다.

- 한국어·English·日本語는 기본 제공 문구를 즉시 사용합니다.
- 언어 목록 외에도 원하는 언어 이름이나 코드(예: `Deutsch`, `de`, `pt-BR`, `தமிழ்`)를 직접 입력할 수 있습니다. 선택 가능한 언어를 고정 목록으로 제한하지 않습니다.
- 기본 제공하지 않는 언어는 처음 선택할 때 Claude로 화면 문구를 번역합니다. 이때 Claude 로그인과 실행 중인 최신 도우미가 필요하며 구독 사용량이 소모됩니다.
- 준비된 화면 문구는 `%LOCALAPPDATA%\BalloonLens\ui-locales`에 저장해 재사용합니다. 자동 번역이므로 언어별 표현 품질에는 차이가 있을 수 있습니다.
- 화면 언어를 바꿔도 만화 원문·번역문·작품 지침은 바뀌지 않습니다. 프로그램과 확장은 각자 선택을 저장하며, 확장의 팝업·설정·열린 번역 화면은 선택을 공유합니다.
- 이 기능을 적용하려면 도우미와 프로그램을 다시 시작하고 크롬 확장을 새로고침합니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 번역 켜기/끄기 | 팝업의 큰 버튼 / `Alt+Shift+T` / 페이지 오른쪽 아래 ✕ |
| 이미지가 안 잡힐 때 | 팝업 `영역 번역` / `Alt+Shift+R` → 드래그 |
| 원문 잠깐 보기 | 팝업 `원문 보기` / 페이지 눈 아이콘 / `Alt+Shift+O` |
| 대사 고치기 | 번역된 말풍선 클릭 → 원문·번역 수정 → `저장` (Ctrl+Enter) |
| 말풍선 범위·번역 칸 고치기 | 말풍선 클릭 → `영역 편집` / 페이지 오른쪽 아래 편집 아이콘 |
| 이름 표기 통일 | 말풍선 클릭 → `용어 추가` |
| 페이지 대사를 글로 보기·찾기·복사 | 팝업 `대사 목록` / `Alt+Shift+L` |
| 설정 옮기기·되살리기 | 설정 화면 `설정 백업` |
| 페이지 넘어가도 이름·말투 유지 | 팝업 `이 작품 등록하기` → 설정에서 제목·인물 적기 |
| 다른 모델로 한 줄만 | 말풍선 클릭 → `Qwen3로` / `TranslateGemma로` |
| 늘 켜기 | 팝업의 `이 사이트에서 자동으로 켜기` |

### 자동으로 되는 것

- **미리 읽기:** 화면에 걸친 이미지를 모두 번역하고, 읽는 방향(설정의 `rtl`·`ltr`·`ttb`) 쪽 가장 가까운 한 장을 미리 번역합니다. 가로로 펼친 뷰어에서는 화면 밖 페이지를 번역하지 않습니다.
- **병렬 처리:** 이미지 인식은 바로 시작하고, 번역 호출은 최대 3개가 동시에 나갑니다.
- **대기 줄이기:** 이미지 인식 중 Claude 프로세스를 미리 준비하고, 번역 응답을 기다리는 동안 말풍선 표시도 준비합니다. 프로세스 준비만으로는 번역 호출이 나가지 않습니다.
- **캐시:** 같은 이미지와 같은 줄, 같은 설정이면 저장된 번역을 씁니다. 다시 방문해도 같은 줄은 모델을 다시 부르지 않습니다.
- **한도 멈춤:** 한도에 닿으면 멈추고 재개 시각을 보여줍니다. `로컬로 계속`을 누르면 로컬 모델로 이어서 번역합니다. 재개 시각을 알 수 없으면 30분, 1시간, 2시간 순으로 기다립니다.
- **취소:** 페이지를 떠나거나 번역을 끄면 아직 시작하지 않은 호출은 나가지 않고, 실행 중인 호출의 프로세스는 멈춥니다.
- **글자 칸:** 번역이 칸에 안 들어가면 칸을 최대 2배까지 키웁니다. 다른 번역 칸은 덮지 않습니다. 그래도 넘치면 `…` 표시가 나오고, 눌러서 전체 문장을 봅니다.
- **검수:** 설정의 `대사 검수`에서 자동·끔·필요한 대사만·모든 대사 중에서 고릅니다. 자동은 로컬 모델에서 필요한 대사만 다시 검수하고, 구독에서는 끕니다.

## 설정

설정 카드에서 구독 상태와 Claude 남은 사용량을 확인하고 로그인 명령을 복사할 수 있습니다. 도우미를 실행하는 환경 변수는 다음과 같습니다.

| 환경 변수 | 기본값 | 뜻 |
|---|---|---|
| `BALLOONLENS_PORT` | `8787` | 도우미 포트 (127.0.0.1 전용) |
| `BALLOONLENS_DATA` | `%LOCALAPPDATA%\BalloonLens` | 데이터 폴더 |
| `BALLOONLENS_CLI_PARALLEL` | `3` (1–4) | 동시에 나가는 구독 호출 수. `1`이면 한 번에 하나씩 |
| `BALLOONLENS_CLI_TIMEOUT` | `150` | 구독 호출 하나의 제한 시간(초) |
| `BALLOONLENS_CLI_WARM` | `2` (0–4) | 미리 켜 두고 기다리는 Claude 프로세스 수. 하나에 메모리 약 180MB를 쓰고 10분 안 쓰면 꺼짐. `0`이면 호출마다 새로 켬 (더 느림) |
| `BALLOONLENS_CLAUDE_EFFORT` | `low` | Claude 추론 강도 |
| `BALLOONLENS_CLAUDE_CONFIG_DIR` | `데이터 폴더\claude-config` | Claude 전용 로그인 폴더 |
| `BALLOONLENS_EXTENSION_IDS` | 이 프로젝트의 확장 ID | 연결을 허용할 확장 ID 목록 (쉼표 구분) |
| `OLLAMA_HOST` | `127.0.0.1:11434` | Ollama 주소 |
| `BALLOONLENS_KEEP_ALIVE` | `15m` | Ollama 모델을 메모리에 두는 시간 |

## 데이터와 개인정보

모든 데이터는 `%LOCALAPPDATA%\BalloonLens`에 있습니다. 설치 창의 **데이터 폴더 열기** 버튼으로 바로 열 수 있습니다.

| 파일 | 내용 |
|---|---|
| `cache.sqlite3` | `ocr`: 글자 인식 결과(원문 포함, 이미지 해시로 찾음). `tr`: 번역 결과(키는 해시). `edits`: 직접 고친 원문·번역. `layouts`: 영역 편집. `works`·`pages`: 작품 정보와 작품 기억. `usage_events`: 구독 호출 수와 토큰 수(대사 글자 없음) |
| `metrics.jsonl` | 작업별 수치(상태, 시간, 줄 수). 대사 내용은 없습니다. 실패 기록에는 오류 코드만 남습니다 |
| `helper.log` | 도우미 실행 기록 |
| `claude-config\` | Claude 번역 전용 로그인 폴더 |

- 이 PC의 파일에는 원문 대사가 들어 있습니다(글자 인식 결과, 작품 기억, 직접 고친 내용).
- 구독 번역을 쓰면 현재 페이지 대사, 작품 지침·용어집, 작품 기억의 앞 페이지 대사가 해당 서비스로 갑니다. 이미지와 설정 파일은 나가지 않습니다.
- 로컬 Ollama 번역은 아무것도 밖으로 내보내지 않습니다.
- 데이터 폴더를 지우면 캐시와 기록이 모두 사라집니다.

## 구성

| 단계 | 방식 |
|---|---|
| 확장 | Chrome MV3. 말풍선 표시, 팝업, 설정, 대사 목록, 편집기. 빌드 과정 없음 |
| 도우미 | Python, FastAPI, `127.0.0.1:8787`. Host·Origin 검사, 확장 ID 기반 자동 연결 |
| 작업 큐 | 글자 인식은 한 번에 한 장(GPU). 구독 작업은 최대 6개 동시에 진행하고, 번역 호출은 최대 `CLI_PARALLEL`개 |
| 글자 검출 | EasyOCR CRAFT로 글자 상자를 찾고, 가까운 상자를 말풍선 단위로 묶습니다. 긴 웹툰은 겹치는 타일로 나누고, 화면에 보이는 타일부터 검출합니다 |
| 글자 인식 | 일본어는 Manga OCR, 영어는 EasyOCR. 화면에 보이는 말풍선부터 읽고, 의심스러운 결과만 전처리를 바꿔 모아서 다시 읽습니다 |
| 번역 | 구독 CLI(Claude Code) 또는 로컬 Ollama. 구독은 JSON 구조화 출력과 결과 검사를 거칩니다 |
| 배치 | 닫힌 밝은 말풍선 안쪽을 분석하고, 원문 글자를 지운 PNG 패치를 씁니다. 한국어는 어절 단위로 줄바꿈합니다 |

## 개발 환경

필요한 것: Windows, Python 3.11, Node.js(노드 테스트용), Git. GPU가 없으면 OCR을 `--cpu`로 돌립니다.

```powershell
python -m venv helper\.venv
helper\.venv\Scripts\python.exe -m pip install torch==2.6.0 torchvision==0.21.0 --index-url https://download.pytorch.org/whl/cu124
helper\.venv\Scripts\python.exe -m pip install -r helper\requirements.txt
```

도우미를 직접 켜기:

```powershell
cd helper
.venv\Scripts\python.exe -m balloonlens
```

글자 인식 모델은 켜지는 즉시 올라가고 한 번씩 돌려 봅니다. 올라가는 동안 도착한 페이지는 그 뒤에 처리됩니다. 첫 페이지가 올 때 올리려면 `--no-warmup`을 붙입니다.

### 테스트

프로젝트 루트에서 실행합니다.

```powershell
helper\.venv\Scripts\python.exe -m pytest -q
node --test tools\test_extension.cjs tools\test_reading.cjs tools\test_editor.cjs tools\test_subscription_ui.cjs
```

구독 번역 테스트는 실제 구독을 쓰지 않습니다. 가짜 CLI로 한도, 취소, 병렬 호출을 확인합니다. 실제 구독 사용량을 쓰는 도구(`balloonlens.bench`)는 `--live`를 붙여야만 모델을 부릅니다.

### 검증 도구

| 도구 | 용도 |
|---|---|
| `tools\e2e_subscription.py` | 구독 경로를 가짜 CLI로 확인. `--with-ocr`를 붙이면 실제 글자 인식까지 |
| `tools\e2e_subscription_live.py` | 실제 확장과 실제 도우미를 연결해서 팝업·설정 카드, 연속 번역, 앱 횟수 제한 제거를 확인 (가짜 CLI, 모델 호출 없음) |
| `tools\e2e_subscription_auto.py` | 자동 실행과 미리 읽기 범위 확인 (모델 호출 없음) |
| `tools\e2e_regions.py`, `tools\e2e_convenience.py` | 영역 편집, 대사 목록, 설정 백업 확인. 두 번째는 가짜 응답으로 돌아감 |
| `tools\e2e_extension.py` | Playwright Chromium에서 확장 전체 흐름 확인. Ollama와 두 모델이 필요함 |
| `tools\review_compare.py` | 선택 검수와 전체 검수 비교 |
| `tools\blind_eval.py` | 사람이 하는 A/B 블라인드 평가 준비와 집계 |
| `python -m balloonlens.bench` | 로컬 모델의 속도와 VRAM, 번역 비교 |
| `python -m balloonlens.ocr_profile` | 번역 없이 글자 인식만 단계별로 재기. 내 만화 페이지로 확인할 때 |
| `python -m balloonlens.metrics_report` | `metrics.jsonl`에서 단계별 시간과 병목 진단 |
| `tools\pipeline_bench.py` | 읽는 동안 번역을 시작하는 방식의 득실을 가짜 번역기로 확인 (Claude 호출 없음) |

합성 샘플(`samples\synthetic`)은 연결 확인용입니다. 번역 품질의 근거가 아닙니다. 실제 만화는 `samples\real\`에 넣어서 쓰며, 저장소에는 포함하지 않습니다.

### 배포

- 설치 창 exe: `tools\build_setup_exe.ps1`
- 화면 번역 프로그램 exe: `tools\build_desktop_exe.ps1` (프로젝트 폴더와 `release`에 생성, 설치된 `helper\.venv` 사용)
- 배포 ZIP: `tools\build_package.py` (ZIP에는 로그인 정보, 캐시, 로그, 실제 샘플이 들어가지 않도록 검사합니다)

## 알려진 제한

- **실제 만화 품질은 아직 측정하지 않았습니다.** 합성 샘플로만 확인했고, 실제 사이트에서의 번역 품질, 글자 인식률, 호출 수는 모릅니다.
- **번역 칸을 키우면 그림이나 말풍선 테두리를 덮을 수 있습니다.** 지금은 다른 번역 칸과만 겹치지 않게 막습니다. 그림까지 막으려면 말풍선 윤곽 정보가 필요합니다.
- **앞 페이지 인물 이름을 고쳐도 뒤 페이지 번역은 자동으로 다시 되지 않습니다.** 캐시를 아끼려고 한 설계의 대가입니다.
- **번역 시간은 페이지와 Claude 응답 상태에 따라 달라집니다.** 프로세스 준비와 말풍선 표시 준비를 겹쳐 대기를 줄였지만, 실제 만화 사이트에서의 단축률은 아직 측정하지 않았습니다. [변경 전후 검증](docs/superpowers/plans/2026-10-13-latency-overlap.md)을 참고하세요.
- **원문 지우기는 닫힌 밝은 말풍선만 됩니다.** 열린 말풍선, 어두운 배경, 복잡한 배경은 흰 바탕으로 덮어서 보여줍니다.
- **긴 웹툰의 의미 단위 분할은 아직 없습니다.**
- Claude 남은 사용량은 내부 사용량 조회 경로를 사용합니다. 이 경로가 바뀌거나 조회가 제한되면 확인 불가로 표시되며 번역 자체는 계속 사용할 수 있습니다.
- 구독 CLI 자동화의 약관 해석은 법률 검토가 필요합니다. 구독 번역 결과로 다른 모델을 학습하는 것은 약관 검토 전에는 하지 않습니다.
- 자동 업데이트는 없습니다. 새 버전은 ZIP을 다시 받아 설치합니다.
