# 말풍선 렌즈 · BalloonLens

기획서: [BalloonLens_Product_Plan_v1.0.md](BalloonLens_Product_Plan_v1.0.md)

크롬에서 보는 만화 이미지 속 대사를 번역해서, 원래 말풍선 자리에 한국어로 보여주는 확장 프로그램입니다. 번역은 두 가지 중 하나를 고릅니다. 이 PC의 로컬 모델(Ollama), 또는 이미 가진 Claude Code·Codex 구독입니다. 번역 서비스로는 이미지를 보내지 않습니다. 구독을 고르면 대사 글자만 나가고, 처음 쓰기 전에 동의를 받으며, 설정한 한도(5시간·7일)를 넘으면 자동으로 멈춥니다. 개인 PC에서 본인 구독으로 쓰는 것을 전제로 합니다.

## 빠른 시작 (Windows)

1. 배포 ZIP을 풀고 `BalloonLens-Setup.exe`를 더블클릭합니다.
2. 설치 창에서 **전부 자동으로 준비**를 누릅니다. 처음에는 수 GB를 받아서 시간이 걸립니다.
3. 설치 창의 **크롬 확장 설치 안내** 3단계를 따라 크롬에 확장을 로드합니다.
4. **Claude 로그인 창 열기**로 열린 창에서 직접 로그인하고, 설치 창에서 **상태 다시 확인**을 누릅니다.

자세한 설치와 문제 해결은 아래 `설치 (Windows, 한 번만)`을 보세요.

## 설치 (Windows, 한 번만)

**가장 쉬운 방법:** ZIP을 풀고 **`BalloonLens-Setup.exe`를 더블클릭**한다. 창에서 **전부 자동으로 준비**를 누르면 Python 환경, 번역 패키지, 자동 실행 등록을 한 번에 준비한다(처음에는 수 GB를 받아서 시간이 걸린다). 상태 줄이 '준비됨'과 '로그인 됨'이 되면 끝이다. Claude와 Codex 로그인은 **로그인 창 열기** 버튼으로 열린 창에서 직접 한다. 이 프로그램은 로그인 정보를 다루지 않는다. 크롬 확장은 **크롬 확장 설치 안내** 창의 3단계를 따라 한다. 창이 크롬 프로필 설정을 읽어서 설치가 끝나면 '설치 완료'로 바뀐다. 크롬은 보안상 확장을 조용히 설치하지 못하게 막고 있어서, '압축해제된 확장 프로그램 로드'를 누르는 한 번은 사람이 해야 한다. 확장은 프로필마다 따로 설치되므로 평소 쓰는 프로필을 고른다. 포트 8787을 다른 프로그램이 쓰고 있으면 창에 그 이름이 나온다. 그 프로그램을 끄고 **상태 다시 확인**을 누른다. 개발자는 `tools\build_setup_exe.ps1`로 exe를 다시 만든다. 아래의 수동 설치 방법도 그대로 쓸 수 있다.


통합 ZIP에서는 압축을 풀고 **`Setup.cmd`**를 한 번 실행한다. Python 환경, 번역 의존성, 도우미 연결, Claude Code·Codex 설치 확인을 순서대로 준비한다. Ollama와 로컬 모델은 선택 사항이라 `Setup.cmd -WithLocal`로 함께 설치한다. 처음 다운로드는 수 GB이며 인터넷이 필요하다. `Setup.cmd`는 구독에 로그인하지 않는다. 크롬 확장은 `chrome://extensions` → 개발자 모드 → **압축해제된 확장 프로그램 로드**에서 `extension` 폴더를 선택한다. ZIP 설치 경로는 이후에도 유지한다.

이미 이 프로젝트를 사용 중이면 도우미를 재시작하고 크롬 확장과 대상 페이지를 새로고침한다. 기존 설치의 모델 선택은 그대로 남고, 구독 번역은 자동으로 켜지지 않는다. 구독을 쓰려면 팝업에서 `Claude 구독` 또는 `Codex 구독`을 고르고 동의한다.

개발 환경을 직접 준비하는 방법:

1. **파이썬 환경** — Python 3.11, PowerShell에서 아래 순서로 설치한다. CUDA torch도 반드시 생성한 가상환경에 설치한다:
   ```powershell
   python -m venv helper\.venv
   helper\.venv\Scripts\python.exe -m pip install torch==2.6.0 torchvision==0.21.0 --index-url https://download.pytorch.org/whl/cu124
   helper\.venv\Scripts\python.exe -m pip install -r helper\requirements.txt
   ```
2. **구독 CLI** (권장) — Claude Code 2.1.268 이상과 Codex CLI(`npm install -g @openai/codex`)를 설치한다. **Ollama** (선택) — 로컬 모델을 쓸 때만 https://ollama.com/download 에서 설치하고, 모델은 확장 설정 화면에서 받는다.
3. **확장 로드** — `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드 → `extension/`
4. **도우미 자동 실행 등록** — `tools\install_windows.cmd` 더블클릭. 현재 사용자 레지스트리에 크롬 네이티브 메시징 호스트를 등록해서, 번역을 켤 때 크롬이 도우미를 알아서 켠다. 해제는 `tools\uninstall_windows.ps1`.

확장을 처음 설치하면 **시작하기** 화면이 열리고, 남은 설정(도우미·모델·권한)과 샘플 번역을 차례로 확인할 수 있다. 토큰 복사는 필요 없다 — 확장 ID가 고정돼 있어서 도우미가 이 확장에만 자동으로 연결을 허락한다.

구독 로그인은 한 번만 한다. Claude는 번역 전용 폴더에 로그인해서 개인 설정(CLAUDE.md)과 섞이지 않게 한다:

```powershell
$env:CLAUDE_CONFIG_DIR = "$env:LOCALAPPDATA\BalloonLens\claude-config"; claude auth login
```

Codex는 ChatGPT 계정으로 로그인한다:

```powershell
codex login
```

확장 설정 화면의 각 카드에도 같은 명령이 있고 복사 버튼이 붙어 있다.

도우미를 직접 켜고 싶으면:

```bash
cd helper && .venv\Scripts\python.exe -m balloonlens --warmup
```

## 쓰는 법

0.5.0 새 기능 (구독 번역):

- **번역 방식 고르기** — 팝업에서 `Claude 구독`(Haiku 5.5), `Codex 구독`(luna), `로컬`(Qwen3.5) 중 하나를 고른다. 구독을 고르면 처음 한 번 사용 안내를 읽고 동의해야 번역이 나간다. 안내 문구가 바뀌면 다시 동의한다.
- **보내는 것** — 구독에는 대사 글자만 나간다: 지금 페이지 대사, 작품 지침·용어집, 작품 기억에서 고른 앞 페이지 대사. 이미지, API 키, 설정 파일은 나가지 않는다.
- **한도와 일시정지** — 5시간·7일 호출 상한(기본 20회·150회)에 닿으면 자동으로 멈추고 다시 시작할 시각을 보여준다. `로컬로 계속`을 누르면 로컬 모델로 이어서 번역한다. 상한은 이 PC가 센 호출 수이며 공식 사용량과 다르다. 설정 화면에서 공식 사용량 퍼센트를 두 번 적으면 호출 1회당 대략의 소모율을 계산한다.
- **Codex 보안 점검** — Codex는 샌드박스 점검을 통과해야만 번역한다. 점검은 모델을 부르지 않고 이 PC의 샌드박스 러너로 두 파일을 읽어 본다. 이 PC에서는 읽기 전용 샌드박스가 사용자 폴더의 파일을 읽을 수 있었다(아래 제한 참고). 그래서 Codex 번역은 꺼져 있다.
- **검수** — 설정의 `대사 검수`에서 자동·끔·필요한 대사만·모든 대사 중에서 고른다. 자동은 로컬에서 필요한 대사만 검수하고, 구독에서는 끈다.
- **설정 화면** — 구독마다 카드가 있다: 상태, 동의·철회, 로그인 명령 복사, 한도 저장, 사용 기록, 일시정지 풀기.

0.4.0 새 기능:

- **대사 목록** — 팝업 `대사 목록` / 페이지 오른쪽 아래 목록 아이콘 / `Alt+Shift+L`. 페이지의 모든 대사를 이미지 순서대로 글로 보여준다. 원문·번역 검색, `전체 / 확인 필요 / 직접 고침` 필터, 줄을 누르면 그 말풍선으로 이동해 편집 창이 열린다. `번역 복사` / `원문+번역 복사`는 지금 목록에 보이는 줄만 복사한다. 번역이 꺼진 페이지에서 열면 번역을 먼저 켠다.
- **팝업 `영역 편집`** — 화면에서 가장 크게 보이는 이미지의 편집기를 바로 연다.
- **영역을 옮겨도 직접 고친 내용 유지** — 글자 영역을 옮기거나 크기를 바꾸면 그 대사에 직접 고친 원문·번역이 새 영역으로 따라간다. 나누기·합치기로 새로 생긴 영역은 새 대사로 본다.
- **설정 백업** — 설정 화면 `설정 백업`에서 번역 설정·자동 사이트·작품별 말투·용어·작품 정보를 JSON 파일로 저장하고 불러온다. 기억한 페이지, 캐시, 연결 토큰은 넣지 않고, 불러올 때 알 수 없는 항목이나 잘못된 값은 건너뛴다.
- 편집기에서 지금 편집하지 않는 상자의 이름표를 숨겨 겹침을 없앴다.

0.3.0 새 기능:

- **영역 편집** — 말풍선을 눌러 `영역 편집`, 또는 페이지 오른쪽 아래 편집 아이콘. `글자 영역`(무엇을 읽고 지울지)과 `번역 영역`(번역문을 어디에 넣을지)을 따로 고친다. 옮기기·크기 조절(모서리)·추가·좌우/위아래 나누기·합치기·삭제·되돌리기(Ctrl+Z)·다시 실행(Ctrl+Y)을 지원하고, `저장하고 다시 번역`하면 그 이미지에 저장돼 다시 방문해도 유지된다. 옮긴 글자 영역은 다시 읽는다. 원본 이미지를 받은 경우에만 저장된다(화면 캡처 번역은 불가).
- **작품별 기억** — 팝업의 `이 작품 등록하기`로 작품 주소를 등록한 페이지에서만 켜진다. 번역한 원문·번역문(직접 고친 표현 표시 포함)을 기억해 다음 페이지 번역에 가까운 대사부터 참고로 넣는다. 주소에 페이지 번호가 있으면 뒤 페이지 내용은 앞 페이지에 쓰지 않는다. 같은 이미지를 규칙 변경 없이 다시 열면 기억한 번역을 그대로 써서 모델을 다시 부르지 않는다. 설정 화면에서 제목·확인한 줄거리·인물(이름 = 한국어 · 말투 · 관계)을 적을 수 있고, `기억에서 제안 받기`는 모델이 추측한 후보를 보여줄 뿐 저장은 직접 확인한 것만 한다.
- **용어 추가** — 말풍선 창의 `용어 추가`로 `원문 = 한국어`를 작품 용어집에 바로 넣는다. 원문·번역 칸에서 단어를 선택한 뒤 누르면 채워진다. 추가하면 현재 페이지를 새 용어로 다시 번역한다.
- **OCR 부분 재시도** — 빈 결과·글자 없는 결과·같은 글자 반복·낮은 신뢰도·영역에 비해 너무 짧은 결과만 여백·대비·이진화를 바꿔 다시 읽는다. 그래도 불확실하면 번역은 보여주되 `확인 필요`로 표시한다.
- **필요한 대사만 검수** — Qwen3.5는 숫자, 이름, 용어집 단어·충돌, 권유형(〜しよう), 사라진 물음표, 반말 지침과 다른 존댓말, OCR 불확실, 모델 스스로 불확실 표시가 있는 대사만 한 번 더 검수한다. 설정의 `모든 대사 다시 검수`로 이전처럼 전부 검수할 수 있다. 검수 대상이 아닌 대사에 오역이 없다는 뜻은 아니다.

0.2.2는 번역 박스와 글자 크기를 **원본 글자 영역 기준**으로 제한한다. 큰 말풍선 전체를 채우거나 세로 대사의 높이를 기준으로 흰 박스를 크게 넓히지 않는다. 긴 번역이 넘치면 대사를 눌러 전문을 확인할 수 있다. 크기 조정에는 추가 모델 호출이 없다.

0.2.1 편의 기능: 팝업의 **A− / A+ / 100%**로 글자 크기 조절·초기화, **실패한 부분 재시도**로 실패한 작업/대사만 복구, **확인할 대사 보기**로 실패·검토·넘침 대사를 차례로 찾아 편집할 수 있다. 말투 설정에서는 자연스럽게·반말·존댓말 프리셋을 선택한 뒤 저장한다. 재시도는 직접 고친 대사를 덮어쓰지 않으며, 복구된 자동 번역은 현재 페이지에 반영된다.

| 하고 싶은 것 | 방법 |
|---|---|
| 번역 켜기/끄기 | 팝업의 큰 버튼 / `Alt+Shift+T` / 페이지 오른쪽 아래 ✕ |
| 이미지가 안 잡힐 때 | 팝업 `영역 번역` / `Alt+Shift+R` → 드래그 |
| 원문 잠깐 보기 | 팝업 `원문 보기` / 페이지 눈 아이콘 / `Alt+Shift+O` |
| 대사 고치기 | 번역된 말풍선 클릭 → 원문·번역 수정 → `저장`(Ctrl+Enter) |
| 말풍선 범위·번역 칸 고치기 | 말풍선 클릭 → `영역 편집` / 페이지 오른쪽 아래 편집 아이콘 |
| 이름 표기 통일 | 말풍선 클릭 → `용어 추가` |
| 페이지 대사를 글로 보기·찾기·복사 | 팝업 `대사 목록` / `Alt+Shift+L` |
| 설정 옮기기·되살리기 | 설정 화면 `설정 백업` |
| 페이지 넘어가도 이름·말투 유지 | 팝업 `이 작품 등록하기` → 설정에서 제목·인물 적기 |
| 다른 모델로 한 줄만 | 말풍선 클릭 → `Qwen3로` / `TranslateGemma로` |
| 말투·인명 통일 | 팝업 `이 작품의 말투·용어 설정` → 작품 주소와 규칙 저장 |
| 장면 이미지도 참고 | 설정의 `장면도 참고하기` 켜기 → Qwen3.5 선택. 기본은 끔 |
| 늘 켜기 | 팝업의 “이 사이트에서 자동으로 켜기” |

- 저장한 수정은 도우미에 남아서 다시 방문해도 유지된다(원본 이미지를 받은 경우). 화면 캡처로 번역한 대사는 그 페이지에서만 유지.
- 번역 진행 상황은 툴바 아이콘 배지(`…` 처리 중 / `ON` 완료 / `!` 연결 끊김)와 페이지 오른쪽 아래 상태 표시에 나온다.

## 구성

| 단계 | 사용 기술 |
|---|---|
| 글자 검출 | EasyOCR CRAFT → 가까운 박스를 말풍선 단위로 묶음, 긴 웹툰은 겹치는 타일. 읽은 뒤 사용자 영역 수정(삭제·추가·번역 칸)을 적용 |
| 일본어 / 영어 인식 | Manga OCR / EasyOCR. 의심스러운 결과만 전처리를 바꿔 재인식 |
| 번역 | 구독 CLI: Claude Code `claude-haiku-5-5`(`claude -p`, 도구 끔, 구조화 출력) / Codex `gpt-6-luna`(`codex exec`, 읽기 전용 샌드박스, 점검 통과 후에만). 로컬 Ollama: `qwen3.5:9b`(문맥+필요한 대사 검수) / `qwen3:8b`(문맥) / `translategemma:4b`(한 줄씩 빠르게) |
| 문맥 | 전체 페이지 원문 + 같은 페이지 앞 이미지 대사 + 등록한 작품의 앞 페이지 기억 + 작품 지침·용어집·확인한 작품 정보 |
| 배치 | 닫힌 밝은 말풍선 내부 분석, 글자 제거 PNG 패치, 한국어 어절 우선 줄바꿈 |
| 저장 | SQLite (`%LOCALAPPDATA%\BalloonLens`) — OCR·번역 캐시, 사용자 수정, 영역 수정, 작품 기억(작품당 최근 300장) |
| 연결 | 127.0.0.1 전용, Host·Origin 검사, 확장 ID 기반 자동 페어링 토큰 |

## 검증 도구

프로젝트 루트의 PowerShell에서:

```powershell
helper\.venv\Scripts\python.exe -m pytest -q
node --test tools\test_extension.cjs
node --test tools\test_reading.cjs
node --test tools\test_editor.cjs
node --test tools\test_subscription_ui.cjs
```

영역 편집·용어 추가·작품 기억은 실제 확장과, 사용자 데이터와 분리된 테스트 도우미(8788 포트, 임시 폴더)로 확인한다. Ollama에 Qwen3.5가 있어야 한다:

```powershell
helper\.venv\Scripts\python.exe tools\e2e_regions.py
```

대사 목록·설정 백업·팝업 버튼은 모델 없이 가짜 응답으로 확인한다:

```powershell
helper\.venv\Scripts\python.exe tools\e2e_convenience.py
```

선택 검수와 전체 검수를 같은 OCR 입력으로 비교한다(모델 호출 수·검수한 줄·시간, 결과가 다른 줄 목록). 결과가 다른 줄은 사람이 판단해야 한다:

```powershell
helper\.venv\Scripts\python.exe tools\review_compare.py samples\synthetic
```

브라우저 검증 의존성과 Chromium이 없으면 먼저 설치한다:

```powershell
helper\.venv\Scripts\python.exe -m pip install -r helper\requirements-dev.txt
helper\.venv\Scripts\python.exe -m playwright install chromium
helper\.venv\Scripts\python.exe tools\e2e_extension.py
```

E2E는 실제 확장을 Playwright Chromium에 올려서 시작하기 화면 → 샘플 번역 → 팝업으로 켜기 → 핫링크 차단 이미지의 상·하단 화면 캡처 → 말풍선 수정·저장 → 새로고침 후 한국어 저장값 유지 → 원문 보기·끄기 → 영역 드래그 → 사이트 자동 실행 → 두 모델의 영어 번역을 확인한다. `bench_out\e2e\<실행 ID>\`에 스크린샷을 남기며 이전 결과는 삭제하지 않는다. 도우미와 Ollama가 켜져 있고 두 모델이 설치되어 있어야 한다. 일반 E2E는 연결된 도우미에 샘플 대사 수정을 저장한다. 사용자 데이터와 분리하려면 아래 자동 실행 검증을 사용한다.

구독 번역은 실제 구독을 쓰지 않고 가짜 CLI로 검증한다. `e2e_subscription.py --with-ocr`를 붙이면 샘플 페이지 한 장을 실제 OCR로 읽어서 구독 경로까지 확인한다. 헬퍼 프로세스를 띄워 동의·한도·샌드박스 게이트와 대사가 로그·DB에 남지 않는지 확인하고, 설정 화면은 Chromium에서 목 헬퍼로 확인한다:

```powershell
helper\.venv\Scripts\python.exe tools\e2e_subscription.py
```

```powershell
helper\.venv\Scripts\python.exe tools\e2e_subscription_ui.py
```

실제 확장과 실제 헬퍼 프로세스를 연결해서 동의부터 설정 철회까지 한 번에 확인한다(가짜 CLI, 모델 호출 없음):

```powershell
helper\.venv\Scripts\python.exe tools\e2e_subscription_live.py
```

구독 모델이 미리 번역하는 범위는 화면과 바로 아래 한 장뿐이다. 실제 확장을 자동 실행해서 확인한다(가짜 CLI, 모델 호출 없음, 8788 포트):

```powershell
helper\.venv\Scripts\python.exe tools\e2e_subscription_auto.py
```

CLI 상태와 Codex 샌드박스를 확인한다. 모델은 부르지 않는다:

```powershell
helper\.venv\Scripts\python.exe tools\probe_backends.py
```

`--live`를 붙이면 구독 사용량을 쓴다(Claude 최대 1회, Codex 번역 최대 1회. Codex 샌드박스 점검은 모델을 부르지 않는다). 결과는 `bench_out\probes\`에 저장되고 배포 ZIP에는 들어가지 않는다. Codex 샌드박스는 사용자 폴더 안에서 시작되지 않을 수 있다. 그럴 때는 `--sandbox-dir`로 다른 작업 폴더를 주고 다시 보면 된다(`--record`를 붙이면 결과를 앱이 읽는다).

사람이 하는 블라인드 평가는 `tools\blind_eval.py prepare`로 준비하고 `score`로 집계한다. 합격 기준은 아직 승인되지 않은 제안치다.

도우미 자동 실행까지 검증하려면 `tools\install_windows.cmd`로 등록 후, 8788 포트가 비어 있는 상태에서:

```powershell
$env:BALLOONLENS_PORT = '8788'
$env:BALLOONLENS_DATA = Join-Path $PWD ('bench_out\native-validation-' + [DateTimeOffset]::Now.ToUnixTimeMilliseconds())
$env:BALLOONLENS_TEST_NATIVE = '1'
# 이 PC의 Ollama 설정. 다른 PC에서는 실제 Ollama 주소를 사용한다.
$env:OLLAMA_HOST = '127.0.0.1:12434'
helper\.venv\Scripts\python.exe tools\e2e_extension.py
```

이 검증은 테스트용 확장 복사본만 8788에 연결한다. 자동 실행한 테스트 도우미는 브라우저가 닫혀도 유지되므로 반복 실행 전 종료해야 한다. 검증용 환경 변수는 현재 PowerShell을 닫으면 해제된다. 일반 실행은 기본 8787을 사용한다.

```bash
$env:PYTHONPATH = 'helper'
helper\.venv\Scripts\python.exe -m balloonlens.bench samples\synthetic --backends local:translategemma:4b,local:qwen3:8b
```

벤치는 모델별 콜드 로딩·페이지 지연·VRAM과 줄별 번역 비교표를 만든다. **합성 샘플은 연결 확인용이지 품질 근거가 아니다.** 실제 만화는 `samples\real\`에 넣고 같은 명령으로 돌리기. 백엔드별 호출 수와 토큰 수도 표에 나온다. `claude`, `codex`는 `--backends claude,codex --live`로 실행하며 구독 사용량을 쓴다(Codex는 샌드박스 점검을 통과한 뒤에만).

## 아직 안 된 것 / 알려진 제한

- 구독 번역은 **개인 PC와 본인 구독**에서만 쓴다. 배포 ZIP에는 구독 로그인이 들어가지 않고, 다른 사람에게 나누면 안 된다. 구독 CLI 자동화의 약관 해석은 법률 검토가 필요하다.
- Codex의 읽기 전용 샌드박스는 이 PC에서 사용자 폴더의 파일을 읽을 수 있었다(2026-10-10 점검). 그래서 Codex 번역은 꺼져 있다. Codex를 업데이트한 뒤 설정 화면의 보안 점검을 다시 해 볼 수 있다. Codex를 켜기 전에는 사용자 AGENTS.md(`%USERPROFILE%\.codex\AGENTS.md`)를 Codex가 읽는지도 확인해야 한다.
- 구독 번역의 실제 품질은 아직 측정하지 않았다. 블라인드 평가는 사람이 해야 하고, 합격 기준은 승인 전이다.
- 구독 한도에 닿고 재개 시각이 메시지에 없으면 30분, 1시간, 2시간 순으로 기다린다. 미리 번역은 화면과 바로 아래 한 장뿐이라, 빨리 넘기면 그 뒤 이미지는 조금 늦게 나온다.
- 구독 상한은 이 PC가 센 호출 수다. 공식 사용량은 자동으로 읽지 않는다(사용자가 퍼센트를 입력).
- 실제 만화 사이트 호환성과 약 30장 실제 샘플 품질 평가(기획서 16.1)는 아직 하지 않았다.
- 원문 언어 자동 감지, 인물 자동 추적은 아직 없다. 작품 기억은 등록한 작품 주소에서만 켜지고, 페이지 순서는 주소 속 숫자로만 판단한다(숫자가 없거나 순서와 무관한 사이트는 읽은 시간 순).
- 필요한 대사만 검수하는 방식은 합성 샘플 4장에서만 비교했다(아래 검증 문서). 실제 페이지에서 품질을 얼마나 유지하는지는 아직 모른다.
- 나누기·합치기한 영역에는 직접 고친 내용이 이어지지 않는다(옮기기·크기 조절은 이어짐).
- 영역 편집은 원본 이미지를 받은 경우에만 저장된다. Canvas·화면 캡처 번역은 편집 저장 불가.
- 원문 제거는 **닫힌 밝은 말풍선만** 지원한다. 열린 말풍선·어두운/복잡한 배경은 기존 흰색 오버레이로 표시한다. Koharu의 학습 기반 검출 모델과 LaMa 인페인팅은 아직 통합하지 않았다.
- Qwen 문맥 입력은 8192 토큰 예산을 보수적으로 검사한다. 너무 긴 페이지는 내용을 몰래 잘라 보내지 않고 `확인 필요`로 표시한다. 길이가 큰 웹툰의 의미 단위 분할은 후속 작업이다.
- 말투·용어집은 모델 입력에 반영되지만 준수를 보장하지 않는다. `확인 필요`는 숫자·언어·응답 불확실성 검사 결과이며, 표시가 없다고 오역이 없는 것은 아니다.
- TranslateGemma 빠른 모드는 작품 지침·문맥을 사용하지 않는다. Qwen 모드에서 사용한다.
- Canvas·배경 이미지 뷰어는 영역 번역으로만 쓸 수 있다.
- 말풍선 묶음은 박스 간격 기준이라 붙은 말풍선이 합쳐질 수 있고, 읽는 순서는 좌표 정렬만 함
- 페이지 기준 영역 번역은 페이지 안쪽 스크롤 영역에서 위치가 어긋남
- 고정 헤더가 이미지를 가리는 사이트에서는 화면 캡처 번역이 가려진 부분을 못 읽음
